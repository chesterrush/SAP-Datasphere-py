# SAP-Datasphere-py
A step-by-step beginner's book on Python for the SAP Datasphere script operator, in English and German. No prior coding needed. Covers pandas, NumPy, Decimal, dates, text cleaning, NULL handling, batch limits and sandbox rules, with tested code, 10 recipes, exercises with solutions and a cheat sheet. Made for SAP BW users new to Datasphere.
